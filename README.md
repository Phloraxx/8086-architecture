# 8086 Microprocessor Architecture Learning Tool

This interactive educational tool helps students learn and practice the Intel 8086 microprocessor architecture through hands-on drag-and-drop activities and connection exercises.


## DOES NOT WORK ON A SMART BOARD USING TOUCH CONTROLS 

- Drag-and-Drop only works using a mouse

## Features

- **Drag-and-Drop Interface**: Intuitive drag-and-drop functionality for placing components
- **Component Library**: All essential 8086 architecture components
- **Connection System**: Draw connections between components to build the architecture
- **Component Information**: Detailed information about each component when selected
- **Validation**: Check your connections against the correct 8086 architecture

## Components Included

1. 8086 CPU
2. 8288 Bus Controller
3. Memory
4. I/O Devices
5. Clock Generator
6. Address Latches
7. Data Buffer
8. Address Lines
9. Data Lines

## How to Use

1. **Open the Application**: Simply open [`index.html`](https://8086e.mulearnscet.in/) in any modern web browser
2. **Drag Components**: Drag components from the left panel to the workspace
3. **Position Components**: Move components around the workspace as needed
4. **Connect Components**: Click on connection points (small circles) and drag between components to create connections
5. **View Information**: Click on any component to see detailed information in the right panel
6. **Check Connections**: Use the "Check Connections" button to validate your work
7. **Get Help**: Use the "Show Hint" button for guidance
8. **Clear Workspace**: Start over with a clean workspace using the "Clear Workspace" button

- **Visual Learning**: See the 8086 architecture come together visually
- **Immediate Feedback**: Real-time validation of connections
